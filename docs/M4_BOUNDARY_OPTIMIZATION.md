# M4 待优化项：栈与全局边界划分

栈和全局边界划分的优化留待后续。当前阶段流程以 M4 基线作为内存分块输入，接下来推进 M5 的寄存器定义与使用关系。[M4 产物契约](M4.md) · [阶段路线图](STAGES.md)

## 48 份 ELF 的基线

本项目基线为 `b48addc`，独立参照为 BPA-X `0fb0a515`。样本覆盖 bzip2、gobmk、h264ref、hmmer、milc、perlbench、sjeng、sphinx3，每个程序各有 32/64 位的 O0、O1、O2 构建。双方用同一份 ELF 的 DWARF 真值和 BPA-X 默认评分规则。栈按「函数入口、相对入口 SP 偏移」比较，全局按 ELF VA 比较，评分对象为变量起始切点。栈真值还包含规则补入的返回地址槽。汇总分数以各样本 TP、FP、FN 的合计计算。

| 范围 | 构建数 | 栈 TP / FP / FN | 栈 Precision / Recall | 全局 TP / FP / FN | 全局 Precision / Recall |
| --- | ---: | ---: | ---: | ---: | ---: |
| 上一批五个程序 | 30 | 12,340 / 1,090 / 15,353 | 91.88% / 44.56% | 757 / 328 / 263 | 69.77% / 74.22% |
| 新增 gobmk、h264ref、perlbench | 18 | 56,596 / 749 / 47,001 | 98.69% / 54.63% | 3,413 / 815 / 691 | 80.72% / 83.16% |
| **合计** | **48** | **68,936 / 1,839 / 62,354** | **97.40% / 52.51%** | **4,170 / 1,143 / 954** | **78.49% / 81.38%** |

全局默认统计覆盖 42 份。hmmer 的六份默认全局真值为空，启用 `--include-statics` 后的补充分数为 **97.35% / 89.55%**，单独保留。48 份中 45 份的 TP、FP、FN 集合与 BPA-X 逐项一致，三份差异均为 perlbench 的栈边界。汇总包含 `sjeng_32_O2` 与 `perlbench_32_O2` 两份隔离复跑，复跑跳过了起始地址落在指令内部的不可解码 CFG 节点。仅统计标准流程时，栈为 **97.45% / 51.56%**，全局为 **78.03% / 80.66%**。

## 统计特性与优化方向

- **栈以补漏为主。** 62,354 个漏报中，旧候选集提出了 50,987 个，按默认评分范围过滤后还有 **50,523 个**可计分。若保留基线命中并选中全部可计分的真候选，召回率可达 **90.99%**。gobmk 占栈真值的 45.84%，按程序等权计算的 Precision / Recall 为 **92.80% / 47.02%**。后续按程序和优化级别核对补点新增的 TP 与 FP。
- **全局需要同时看候选和误报。** 954 个漏报中，旧候选集提出了 431 个，按默认评分过滤后只有 **61 个**可计分，对应的召回上限是 **82.57%**。O0 到 O2 的真值数均为 1,708，召回在 81.21%–81.67% 之间，误报从 295 增至 409、439。后续可分别检查缺失的候选来源和错误的内部切点。
- **评估受真值覆盖影响。** 栈的 O0 可评分真值有 87,708 个，O2 为 19,351 个。当前提取器对优化版 DWARF 位置列表的覆盖有限。全局默认过滤 `.rodata` 预测并保留其中 414 个真值起点。预测与真值都排除 `.rodata` 时，全局召回为 **88.54%**。

候选覆盖统计使用旧模块的来源。栈从 `set_loc_vex_offset` 和 `tmp_reg_offset` 提取偏移。全局使用 `global_chunk_boundary` 和初始化数据中可扫描到的指针目标。候选召回上限假设候选能被完美分类。

## 已有补点实验

本机已有 `/home/qc/Desktop/rebuild/boundary-completion`，封装了冻结的 LightGBM 模型 `stack-gbdt-v1` 和 `global-gbdt-v1`。它从候选集中挑选新增边界并保留基线边界。已有历史报告记录了以下结果，样本和真值口径以各自实验为准。

| 历史实验范围 | Miss% 基线 → 补点 | Wrong% 基线 → 补点 |
| --- | ---: | ---: |
| 栈，六构建留出集 | 23.00% → 8.50% | 5.91% → 5.39% |
| 栈，h264ref 与 gobmk 的 16 个留出构建 | 38.43% → 10.89% | 1.73% → 1.92% |
| 全局，六构建留出集，含 `.data/.bss` 静态对象 | 91.78% → 9.40% | 31.73% → 33.70% |

`Miss% = FN / (TP + FN)`，`Wrong% = FP / (TP + FP)`。历史全局实验的优化收益集中在 gobmk。本轮 48 份 ELF 的结果记录 M4 基线和候选覆盖。恢复该优化时，可先固定样本和真值范围，再复跑已有模型，并按源程序留出测试集。
